# 退换资格调查 SOP

## 适用与必要事实
调查本人具体订单的退货、换货条件。必须知道订单、对应政策和库存；金额、天数来自工具，不能从对话补造。

## 步骤
1. 明确目标；没有单号先 list_my_orders。单笔任务多候选先澄清。
2. get_order 成功后，retrieve_policy 检索该订单政策。
3. 仅用当前任务、当前订单的 evidence_refs 调用 assess_after_sales；不得传入原始 Evidence 或规则文本。
4. 核验完成后调用 check_inventory，库存不足说明换货路径受限，不改变退货结论。

## 失败、确认与停止
政策缺失、冲突、不完整或版本变更时停止对应判断，说明缺口。超期结果必须保留。当前阶段写工具禁用；用户想申请时说明尚未提交，不能把 SOP 的确认描述当作真实授权。后续写入须经过服务端草稿、确认及事务核验。

## 完成条件
policy_assessed：有可信政策核验结果；inventory_checked：有对应订单的库存结果。两项都满足才形成完整退换调查；事实不足应明确结束，不能称已退货或已退款。
