# 订单配送物流 SOP（S5）

## 目的与范围
查询当前登录买家的订单配送进度。本服务为项目 B 固定模拟物流，真实使用 MCP stdio 协议；不是退货运单服务，不推测实时位置或预计送达时间。

## 操作步骤
1. 无单号时调用 list_my_orders，完整分页后多候选先澄清；唯一目标才继续。
2. get_order 重新核验本次目标本人订单，再调用 get_logistics(order_id)。买家与访问凭据由服务端注入，模型不传身份字段。
3. 依据工具结果回答配送状态、来源更新时间及已有运输事件，说明模拟数据和查询时间。暂无记录也是有效查询结果，不能编造轨迹。
4. MCP_TIMEOUT / MCP_UNAVAILABLE 返回后，若有预算可以自主再调用一次，必须使用新的调用 ID。权限拒绝、参数或响应错误不重试。
5. 意外中断后继续物流调查，旧结果仅为历史；重新调用 get_logistics 获取当前记录。不要把历史观察当作刚查到的结果。

## 结束条件
logistics_verified：当前执行段内已得到可信物流结果或明确暂无记录。连接失败或超时必须说明物流查询未完成，其他已核实事实可以展示。这个 Skill 不授予草稿或提交权限。
